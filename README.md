⭐ **Proyecto destacado** — **Vireon**

Vireon es una aplicación SaaS para la gestión de equipos, proyectos y tareas.

El proyecto nació como una idea propia y terminó convirtiéndose en una aplicación completa, incluyendo:

- 🔐Registro y autenticación de usuarios.
- Creación y gestión de equipos.
- Sistema de invitaciones por email.
- Invitaciones mediante enlaces seguro con tokens.
- Gestión de tareas y estados.
- Asignación de tareas a miembros del equipo.
- Recuperación de contraseña.
- Sesiones mediante cookies HTTP-only.
- PostgreSQL + Prisma.
- Despliegue en AWS EC2.
- Base de datos desplegada en AWS RDS.
- HTTPS mediante Nginx + Let's Encrypt.
- Interfaz responsive para escritorio y móvil.
